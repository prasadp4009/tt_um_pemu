# TEMPO tests

Two independent test tracks live here. They share no code on purpose: the
Tiny Tapeout track proves the chip the way the shuttle flow will see it;
the verification track proves the timing contract.

## 1. Tiny Tapeout cocotb test (this directory)

`test.py` + `tb.v` drive the real `tt_um_pemu` top through its pins only:
reset, RD_STATUS in PROG, LOAD_IMEM the 71-word SPI firmware (chunked into
≤63-word frames), VERIFY_IMEM read-back bit-exact, GO, TXFIFO signature
check, HALT_REQ, then a second GO that runs the SPI transaction while the
testbench records the pins — asserting exactly one CS# pulse with exactly
16 SCLK rising edges and MOSI = `0xA5, 0x3C` MSB-first.

```sh
make -B            # RTL simulation (Icarus + cocotb)
make -B GATES=yes  # gate-level, after hardening (needs gate_level_netlist.v)
```

`PROJECT_SOURCES` in the Makefile lists the four RTL files in `src/`
(the same list as `source_files` in `info.yaml`); SRAM macros are modelled
by `sram_sim.v` in simulation.

## 2. Verification regression (independent of the TT track)

```sh
bash test/regress.sh    # from the repo root
```

Stages, in order:

1. **Formal** — 32 SymbiYosys proofs (`test/formal/`, generated by
   `gen.py`/`gen_ext.py`; runner `test/formal/gen/run_all.sh`):
   per-opcode latency and pin effects, prefetch behaviour, FIFO contracts,
   CAP atomicity, Observer watermark, illegal-opcode handling, no-X.
2. **X-check** — `xcheck_pe.v` under Icarus (4-state): no X after reset
   over 600 cycles.
3. **Verilator block benches** — `run_verilator.sh all`: `tb_pe.v`,
   `tb_host.v`, `tb_observer.v`, `tb_top.v` (599 checks total). Lint
   waivers, each tied to one reviewed instance: `lint_waivers.vlt`.
4. **Co-simulation** — `test/cosim/`: all four firmware images
   (SPI/UART/I²C/1-Wire) executed cycle-exactly against the ISA golden
   model's recorded traces.

Coverage closure notes: `COVERAGE.md`. Synthesis check (Yosys, IHP
SG13G2): `test/synth/tempo_synth.ys` → 11,416 cells.
